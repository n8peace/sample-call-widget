# sample-call-widget

A minimal JavaScript widget that adds a call-to-action button to any webpage. When clicked, it reveals three click-to-call options for Financial, Healthcare, and Retail IVAs.

## Usage

Include the script in your page:

```html
<script src="call-widget.js"></script>
```

By default, the widget renders automatically in the bottom-right corner. Update the placeholder phone numbers in `call-widget.js` (`{FINANCIAL_NUMBER}`, `{HEALTHCARE_NUMBER}`, `{RETAIL_NUMBER}`) with real values before deploying.
